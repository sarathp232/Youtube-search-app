# YouTube Search App

A responsive single-page web app that searches YouTube videos using the YouTube Data API v3 and plays them in an embedded player — no page redirects.

## Live Demo
https://sarathp232.github.io/Youtube-search-app/

## Setup
1. Get a free YouTube Data API v3 key from Google Cloud Console
2. Open the app and click "Set YouTube API Key"
3. Paste your key and start searching

## Built with
HTML, CSS, JavaScript (vanilla, no frameworks)
